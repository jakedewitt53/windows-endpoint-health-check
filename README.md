# windows-endpoint-health-check

\# Windows Endpoint Health Check



A PowerShell-based Windows endpoint auditing tool for troubleshooting, inventory, and security checks.



\## Features

* &#x20;Computer name and current user
* Operating system version and build
* Manufacturer and model
* Processor and installed memory
* Disk size and free-space percentage
* Uptime and last reboot time
* Reboot health warning
* Windows Update service status
* BitLocker protection status
* Microsoft Defender status



\## What I Learned

* Using variables and environment variables
* Retrieving Windows system information with Get-CimInstance
* Working with object properties
* Using Get-Service and Windows service information
* Checking BitLocker and Microsoft Defender status
* Writing if, elseif, and else statements
* Using comparison operators such as -eq, -lt, and -ge
* Performing calculations and rounding values
* Troubleshooting PowerShell syntax and execution-policy errors
* Using Git commands such as git status, git diff, git add, git commit, git pull, and git push
* Maintaining a project in GitHub using a local Git repository



\## Project Purpose

* This project was created as part of my PowerShell, Windows administration, and endpoint-management homelab practice.
* The goal is to build practical scripts that can help with endpoint troubleshooting, system inventory, and basic security checks.
